# 画像 → GIFアニメ変換

たくさんの画像(1000枚超もOK)をまとめて、GIFアニメに変換するHTML単体ツールです。
変換はすべてブラウザの中で行われ、画像が外部に送信されることはありません。

- デモ: https://claude.ai/artifact/SiWJ3bjJ1xtLEzLy9f3p4K
- ファイル: `gif-maker.html` 1つだけ(外部ライブラリなし、GIFエンコーダは自前実装)

## 使い方

1. 画像をドロップ、またはエリアをクリックして選択します(複数選択可)。
2. サムネをドラッグして順番を整えます。
3. 1コマの時間や出力幅などを設定します。
4. 「GIFを作成」を押します。
5. 完了したらプレビューを確認して、「ダウンロード」で保存します。

## 画像の並び順

- 追加した順に、あとへ継ぎ足されます(何回かに分けて追加してもOKです)。
- サムネをドラッグして、好きな位置に移動できます。
- サムネにマウスを乗せると右上に × が出て、1枚ずつ削除できます。
- 「名前順に並べ替え」で、ファイル名順(数字は自然順: 2 → 10)に並べ直せます。
- 「順序を反転」で、逆順にできます。
- 「クリア」で、全部取り除けます。

## 設定項目

| 項目 | 内容 |
| --- | --- |
| 1コマの時間(ミリ秒) | 1枚あたりの表示時間です。10ms単位に丸められ、最小は20msです。プリセットボタン(50 / 100 / 200 / 500 / 1000)もあります。 |
| 出力の幅(px) | 16〜1200です。高さは1枚目の縦横比で決まります。 |
| 余白の色 | 白 / 黒です。縦横比が違う画像は、はみ出さないように縮小して中央に置き、余った部分をこの色で埋めます。 |
| ループ | 無限 / 1回のみです。 |

### 容量を減らす設定

| 項目 | 内容 |
| --- | --- |
| 色数 | 256 / 128 / 64 / 32 / 16色です。減らすほど小さくなりますが、グラデーションは段々になります。 |
| コマの間引き | 2〜5コマに1枚だけ使います。再生速度が変わらないよう、1コマの時間を自動で延ばします(動きは少しカクつきます)。 |
| 差分圧縮 | 前のコマから変わらない部分を使い回し、変わった範囲だけを保存します。背景が固定のアニメで特に効きます。 |

差分圧縮の選択肢は次のとおりです。

- **なし**: 毎コマ全体を保存します。
- **劣化なし**(初期設定): 色が完全に同じ部分だけを使い回します。
- **ゆるめ / 強め**: ほんの少しの色の違いも「変化なし」とみなします。さらに小さくなりますが、細かい色の変化は反映されません。

差分圧縮を使うときは、透明色用に1色を確保します。そのため、色数を256にしても実際に使える色は255色です。

## 仕様と注意点

- **色の作り方**: 全コマで共通のパレットを使います。等間隔に選んだ最大30コマから色を集め、メディアンカット法で作ります。ディザリングは行いません。
- **プレビュー**: 300コマを超える場合は自動表示せず、「プレビューを表示」ボタンを押したときだけ表示します。ブラウザは表示のときにGIFの全コマを展開するため、枚数が多いと重くなります。ダウンロードはいつでも使えます。
- **枚数の目安**: 枚数に上限はありません。3000枚を超えると、処理時間とメモリを多く使うという案内が出ます。
- **処理の中止**: 変換中は「中止」ボタンで止められます。
- **読み込めない画像**: 読み込めなかった画像は、飛ばして処理を続けます。
- **ドラッグ操作**: 並べ替えのドラッグは、PCのマウス操作向きです。スマホやタブレットのタッチ操作には、まだ対応していません。
- **動作環境**: `createImageBitmap` に対応した、新しめのブラウザが必要です。

## 技術メモ

- 単一のHTMLファイルで動きます(HTML / CSS / JavaScript)。
- GIFのエンコード(LZW圧縮、グローバルパレット、NETSCAPEループ拡張)は自前で実装しています。
- 差分圧縮は、変化した範囲の外接矩形だけを書き出し、変化のない画素を透明色にします(disposal = 1)。
- 画像は1枚ずつ読み込んで処理するため、元画像を全部メモリに載せることはありません。
- ダークモードに対応しています。
